## OVERVIEW

This project is a **research tool** designed to study how well humans can
distinguish between AI-generated and real audiovisual content (images and
videos). It consists of two independent Streamlit applications:

1. **`app_test.py`** — The test itself. Participants register, take a
   38-item test with images and videos, and get an instant score.
2. **`app_control.py`** — The researcher's dashboard. Loads results from a
   CSV, shows statistics, charts, participant rankings, and provides an
   optional public mode for sharing aggregated results.

Both apps support **Catalan and English**, can run **locally or via Docker**,
and store data in a simple CSV file.

---

## SCIENTIFIC OBJECTIVE

The main research question is:

> **To what extent can humans identify whether audiovisual content has been
> generated by artificial intelligence, and how does this capacity vary
> across demographic factors such as age, gender, and prior exposure to AI
> content?**

### Specific objectives

1. **Measure baseline discrimination capacity** across a diverse sample.
2. **Analyse the influence of age** on detection ability.
3. **Analyse the influence of gender** on detection ability.
4. **Analyse the influence of prior AI exposure** (social media usage) on
   detection ability.
5. **Identify the type of content** (themes) that is hardest to distinguish.
6. **Provide an open, reproducible tool** that other researchers can reuse.

### Hypothesis

We hypothesise that:

- Younger participants have a *slight* advantage, but not as much as commonly
  assumed.
- Exposure to social media **does not** automatically improve detection.
- AI-generated images in themes like *"famous people"* and *"wars/conflicts"*
  are harder to detect than *"animals"* or *"vintage photographs"*.

## WHAT IS THE AICI?

The **AICI (Audiovisual Identification Capacity Index)** is a normalised score
that corrects for random guessing. Since the test is binary (AI vs REAL), a
participant who answers randomly will, on average, get 50% right.

The AICI transforms the raw accuracy into a **-10 to +10 scale**:

```
AICI = ((accuracy% - 50) × 2) / 10
```

| AICI value | Interpretation |
|------------|----------------|
| **+10** | Perfect detection, no guessing |
| **+6 to +10** | High ability |
| **+2 to +6** | Moderate ability |
| **0 to +2** | Slightly better than random |
| **-2 to 0** | Slightly worse than random |
| **-6 to -2** | Moderate confusion |
| **-10 to -6** | High confusion |

The dashboard displays this both as a numerical value and as an aesthetic
semicircular gauge.

## QUICK START

### Prerequisites

- **Option A (Docker):** Docker & Docker Compose
- **Option B (Local):** Python 3.11+, pip

---

### Option A: Docker (recommended)

This is the easiest and most reproducible way.

```bash
# 1. Clone the repository
git clone https://github.com/ElnaGrasaLuna/ai_test.git
cd ai_test

# 2. Make sure the csv/ and images/ folders exist and contain your data
ls csv/       # should show image_list.csv and results.csv
ls images/    # should show the 38 media files

# 3. Build and start both apps
docker compose up -d --build

# 4. Open the apps in your browser
#    Test app:      http://localhost:8501
#    Control panel: http://localhost:8502
```

To stop:

```bash
docker compose down
```

To view logs:

```bash
docker logs -f app_test
docker logs -f app_control
```

---

### Option B: Local Python

```bash
# 1. Clone the repository
git clone https://github.com/ElnaGrasaLuna/ai_test.git
cd ai_test

# 2. Create a virtual environment (recommended)
python3 -m venv .venv
source .venv/bin/activate       # Linux/macOS
# .venv\Scripts\activate        # Windows

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the test app on port 8501
streamlit run app_test.py --server.port=8501

# 5. In another terminal, run the control app on port 8502
source .venv/bin/activate
streamlit run app_control.py --server.port=8502
```

## USING THE TEST APP

1. Open `http://localhost:8501`.
2. Select the language (English / Català) at the top.
3. Fill in the registration form:
   - Full name
   - Age
   - Social media usage / AI exposure level
   - Gender
4. Read the instructions carefully.
5. For each of the 38 items, click **AI** or **REAL**.
6. At the end, you'll see:
   - Your absolute correctness
   - Your AICI score with a visual gauge
   - A breakdown by content type
   - A diagnostic message

The result is automatically saved to `csv/results.csv`.

## USING THE CONTROL DASHBOARD

1. Open `http://localhost:8502`.
2. On the left sidebar:
   - **Language:** English / Català
   - **Active user:** Administrator (with password). If the administrator has
     enabled *public mode*, a *Public* option also appears (aggregated data
     only, no personal names).
   - **Test start/end dates:** the admin can adjust the end date.
   - **Refresh Data** button to reload the CSV.
   - **Shut down** button to stop the Streamlit server.

### Access model

By default, the dashboard is **locked**. Only administrators can see it.
Anonymous visitors see a message explaining that access is restricted.

While logged in as administrator, the researcher can enable **public mode**.
When enabled, the user selector shows two options:

| Role | Password | What they see |
|------|----------|---------------|
| **Administrator** | Yes | Everything: real names, individual responses, raw data, all tabs |
| **Public** | No | Aggregated statistics only. No names, no individual responses, no raw data |

The public mode is reset every time the admin logs out, keeping the
dashboard restricted by default.

### Tabs

| Tab | Admin | Public | What it shows |
|-----|-------|--------|---------------|
| **Global Metrics** | Yes | Yes | Total participants, mean accuracy, mean AICI, gauge, breakdown by age/gender/exposure |
| **Global Charts** | Yes | Yes | 12+ scientific charts: age distributions, exposure analysis, gender analysis, cross-analysis |
| **Participant Inspector** | Yes | No | Individual lookup, response details, ranking table, top-25 / bottom-25 |
| **Content Analysis** | Yes | Yes | Per-image accuracy, error rates, most confusing images |
| **Theme Analysis** | Yes | Yes | Errors grouped by image theme (famous people, wars, etc.) |
| **Analysed Images** | Yes | Yes | Per-image details with preview and demographic breakdown |
| **Raw Data** | Yes | No | Full data table with CSV export |

**Admin password:** set in `app_control.py` (see *Change the admin password*).
**Important:** change it before deploying to any public server.

## DATA FORMAT

### `csv/image_list.csv`

Defines the test items:

```csv
file,solution
1.jpg,AI
2.jpg,REAL
3.jpg,REAL
4.mp4,AI
...
```

- `file`: filename inside `images/`
- `solution`: either `AI` or `REAL`

### `csv/results.csv`

Generated automatically by `app_test.py`. The version included in this
repository is an **anonymised sample** with pseudonymised participant names
(`P001`, `P002`, …). It is included so that anyone cloning the repository can
immediately see the control dashboard working with real-looking data.

Columns:

| Column | Type | Description |
|--------|------|-------------|
| `Date` | string | `YYYY-MM-DD HH:MM:SS` |
| `Participant` | string | Pseudonymised name (`P001`, `P002`, …) |
| `Age` | int | Participant age |
| `IA_Exposure` | string | `never` / `occasionally` / `frequently` / `daily` |
| `Gender` | string | `male` / `female` / `prefer_not_to_say` |
| `Image` | string | Filename shown |
| `Response` | string | `AI` or `REAL` |
| `Solution` | string | `AI` or `REAL` |
| `Correct` | int | `1` if correct, `0` otherwise |

## CUSTOMISATION

### Change the images

1. Put your media files inside `images/`.
2. Update `csv/image_list.csv` with the new file names and solutions.

### Change the theme classification

Edit `THEMES_BY_ID` in `app_control.py`:

```python
THEMES_BY_ID = {
    "Famous people": ["1", "23", "30", ...],
    "Wars and conflicts": ["2", "3", "5", ...],
    ...
}
```

### Change the admin password

In `app_control.py`:

```python
PASSWORD_ADMIN = "your_new_password"
```

Use a strong password (minimum 16 characters, mix of letters, numbers, and
symbols).

### Change the default end date

In `app_control.py`:

```python
DEFAULT_END_DATE = datetime(2028, 1, 1, 0, 0, 0)
```

### Add a new language

Add a new key to the `texts` dict in `app_test.py` and `TEXTS` in
`app_control.py`, then add it to the language selector:

```python
lang_options = {"en": "English", "ca": "Català", "es": "Español"}
```

## DOCKER DEPLOYMENT DETAILS

### Services

| Service | Container | Port | Purpose |
|---------|-----------|------|---------|
| `test-app` | `app_test` | 8501 | Test for participants |
| `control-app` | `app_control` | 8502 | Dashboard for researchers |

### Volumes

Both services share two host folders via bind mounts:

- `./csv` -> `/app/csv` (results and image list)
- `./images` -> `/app/images` (test media)

This means:

- Results written by `app_test` appear immediately on the host.
- Changes to `image_list.csv` or `images/` are picked up without rebuilding.

### Rebuild after code changes

```bash
docker compose down
docker compose up -d --build
```

### Deploy to a server

For production, put the apps behind a reverse proxy (Nginx, Caddy, Traefik)
that adds HTTPS. Example with Nginx:

```nginx
server {
    listen 443 ssl;
    server_name test.example.com;

    location / {
        proxy_pass http://localhost:8501;
    }

    location /control/ {
        proxy_pass http://localhost:8502/;
    }
}
```

If you use the `/control/` sub-path, remember to add the environment variable
`STREAMLIT_SERVER_BASE_URL_PATH=/control` to the `control-app` service in
`docker-compose.yml`.

## TROUBLESHOOTING

### `File not found: csv/results.csv`

The test app has never been completed. Run the test once, and the file
will be created.

### `ModuleNotFoundError: No module named 'pandas'`

Install dependencies:

```bash
pip install -r requirements.txt
```

Or use a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Docker: results.csv not visible on the host

Check that the volume is mounted:

```bash
docker inspect app_test --format '{{json .Mounts}}' | python3 -m json.tool
```

You should see two bind mounts (`csv`, `images`). If not, rebuild:

```bash
docker compose down
docker compose up -d --build
```

### `Permission denied` writing to `csv/`

On Linux, the container runs as root by default and writes files owned by
root. Fix by adding to `docker-compose.yml`:

```yaml
user: "${UID:-1000}:${GID:-1000}"
```

And create a `.env` file:

```
UID=1000
GID=1000
```

### Streamlit on a remote server

If you access the app from another machine, add:

```bash
--server.address=0.0.0.0
--server.port=8501
```

And make sure the port is open in your firewall.

## ETHICS & DATA PROTECTION

This project handles **personal data** (name, age, gender, and answers). It is
the responsibility of the researcher to comply with:

- **GDPR** (EU Regulation 2016/679)
- **LOPDGDD** (Spanish Organic Law 3/2018)
- Any applicable local regulations

### Recommendations

1. **Obtain informed consent** from every participant before they start.
2. **The `csv/results.csv` file included in this repository is anonymised**
   (participant names are pseudonymised as `P001`, `P002`, …). When working
   with real data during a study, do not commit the real file to a public
   repository.
3. **Restrict access to the dashboard** during the study. By default, the
   dashboard is locked and requires the admin password.
4. **Store raw data** on a secure, access-controlled server.
5. **Delete or anonymise personal data** once the research is complete.
6. **Report only aggregated results** in publications.

### Anonymising before publication

Before publishing any dataset with real data, anonymise it. A minimal example
(run locally, not committed):

```python
import pandas as pd

df = pd.read_csv("csv/results.csv")
df["Date"] = pd.to_datetime(df["Date"], errors="coerce")

# Replace each real name with a sequential pseudonym, ordered by first date
first_seen = df.groupby("Participant")["Date"].min().sort_values().reset_index()
mapping = {row["Participant"]: f"P{i+1:03d}" for i, row in first_seen.iterrows()}
df["Participant"] = df["Participant"].map(mapping)

df["Date"] = df["Date"].dt.strftime("%Y-%m-%d %H:%M:%S")
df.to_csv("csv/results_anonymised.csv", index=False)
```

The resulting `csv/results_anonymised.csv` is safe to share.
